# Data Visualisation Project

COS30045 team project on hospitalised injuries from road crashes in Australia, using the BITRE data described in the 2026 project brief.

## Stand-up 1 materials

- `docs/stand-up-1/Design Book Draft.docx` and PDF — current Design Book draft.
- `docs/stand-up-1/Stand-up 1 Presentation.pptx` and PDF — class presentation.
- `docs/stand-up-1/Road Injury Storyboard.pptx` and PDF — proposed viewer journey; findings and final chart choices await data analysis.

## Project folders

- `data/raw/` — source files and data dictionary, with source attribution and terms.
- `data/processed/` — verified, documented exports used by the project.
- `website/` — reserved for later project work; no website implementation is included in this Stand-up 1 commit.

## Project scope

The supplied brief specifies BITRE Hospitalised Injury Data, including national, State/Territory and First Nations series for 2011–2021. The project will develop a focused D3 data story and document data processing, design and usability evaluation. Absolute counts are not population-adjusted rates and must be interpreted with that limitation.
