# Generative AI declaration

OpenAI Codex was used as an assistant during this project.

It was used to:

- help interpret project requirements and organise the work;
- explain and troubleshoot KNIME nodes, formulas, missing values and validation outputs;
- help inspect the processed CSV and check the corrected bed-day calculation;
- assist with drafting and debugging the HTML, CSS, JavaScript and D3 dashboard;
- suggest chart alternatives, interaction patterns and accessibility improvements;
- help structure and format parts of the design book and presentation using evidence supplied by the team;
- help organise the individual reflection without replacing the student's personal experiences; and
- assist with repository cleanup, Git commits and GitHub pushes.

AI did not generate the source data. The data came from the official BITRE Hospitalised Injury release. The team selected the research questions, configured and reviewed the KNIME workflow, checked the processed data, reviewed the dashboard outputs, conducted the usability evaluation, and remains responsible for the accuracy and submission of the work.
