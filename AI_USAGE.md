# Generative AI declaration

OpenAI Codex was used as an assistant during this project.

It was used to:

- help interpret the project requirements and organise the work;
- explain and troubleshoot KNIME nodes and data-processing steps;
- help identify and correct the hospital bed-day calculation;
- assist with the HTML, CSS, JavaScript and D3 implementation;
- suggest and implement chart-accessibility features;
- help check the processed CSV and website behaviour;
- assist with the storyboard and project documentation; and
- assist with Git and GitHub tasks.

The project data was not generated by AI. It came from the official BITRE Hospitalised Injury release. The team selected the analysis questions, configured and reviewed the KNIME workflow, checked the processed data, reviewed the website, and remains responsible for the submitted work.
